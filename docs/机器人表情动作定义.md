# 机器人表情与动作定义

这套视觉语言只使用两只眼睛、头部姿态和整体弹性，不使用嘴巴或眉毛。所有定义都保存在 `src/data/expressions.js`，组件通过 `setExpression(name)` 读取同一份数据。

| 状态 | 眼睛定义 | 头部/身体动作 | 主要含义 |
|---|---|---|---|
| 中性 | 完整竖向胶囊眼 | 保持稳定 | 注视、等待 |
| 喜悦 | 两条上拱弧线，略向中间靠拢 | 压扁后柔和弹跳两次 | 友好、完成 |
| 愤怒 | 双眼压窄、向内倾斜 | 短促左右震动 | 拒绝、警告 |
| 悲伤 | 双眼下移、向外倾斜 | 缓慢下沉再回正 | 失落、失败 |
| 兴奋 | 双眼放大并略微分开 | 连续弹跳三次 | 新消息、重要成功 |
| 惊讶 | 双眼突然放大 | 快速缩小再弹出 | 意外变化 |
| 好奇 | 一只眼眯起、一只眼睁开 | 偏头观察 | 不确定、探索 |
| 困倦 | 双眼变成低矮细条 | 下沉、慢眨眼 | 长时间空闲 |

## 动作节奏

### 两次弹跳 `bounce`

```text
预备压扁 → 第一次向上拉长 → 落地压扁 → 第二次小跳 → 稳定
```

第一次跳跃承担主要反馈，第二次只保留约一半高度，避免无限弹簧感。

### 三次弹跳 `celebrate`

```text
明显压扁 → 高跳 → 中跳 → 小跳 → 稳定
```

用于兴奋和重要成功，不能作为普通悬停反馈频繁播放。

### 震动 `shake`

短促左右移动并轻微压窄，用于拒绝或错误。持续时间控制在一秒以内。

### 叹气 `sigh`

整体缓慢下沉、纵向轻微压缩，再逐渐回到原位，用于悲伤和困倦。

## 代码调用

页面初始化后会暴露：

```js
window.robotAssistant.setExpression("joy");
window.robotAssistant.setExpression("anger");
window.robotAssistant.setExpression("sadness");
window.robotAssistant.setExpression("excitement");
window.robotAssistant.setExpression("surprise");
window.robotAssistant.setExpression("curious");
window.robotAssistant.setExpression("sleepy");
window.robotAssistant.setExpression("neutral");
```

业务事件可以直接映射：

```js
onSaveSuccess:  joy
onImportantSuccess: excitement
onValidationError: anger
onNetworkError: sadness
onUnexpectedUpdate: surprise
onWaitingForInput: curious
onLongIdle: sleepy
```
